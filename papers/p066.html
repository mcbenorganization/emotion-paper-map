PROBLEM · MOTIVATION

研究动机

作者指出：与依赖预先定义的情感分类学的传统歧视范式不同，DMER旨在用自由形态的自然语言来描述人类的情感状态，使更细腻和可解释的情感表现成为可能。分析者归纳：核心瓶颈是常规 token 级训练目标与情感判断、解释质量或人类偏好并不完全一致。

摘要证据： “Unlike traditional discriminative paradigms that rely on predefined emotion taxonomies, DMER aims to describe human emotional state using free-form natural language, enabling finer-grained and more interpretable emotion representations.”
